# Wanderlust 🌍

Wanderlust is a full-stack travel listing web application where users can explore, create, update and review travel listings.

## 🚀 Features

- User Authentication (Register/Login)
- Create new listings
- Edit and delete listings
- Add reviews and ratings
- Image upload using Cloudinary
- Search listings
- Category based filtering
- Interactive maps with location markers using Leaflet.js and OpenStreetMap

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- Bootstrap
- EJS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### Other Tools
- Passport.js (Authentication)
- Cloudinary (Image Storage)
- Leaflet.js (Maps)
- Dotenv (Environment Variables)

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/krishan9576/wanderlust.git
```

Go to project folder:

```bash
cd wanderlust
```

Install dependencies:

```bash
npm install
```

Run project:

```bash
npm start
```
